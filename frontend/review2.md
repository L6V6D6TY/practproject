## 🔴 Блокер: имя файла не совпадает с импортом — сборка падает

В `App.js`, строка 8:

```javascript
import ConfirmDialog from './components/ConfirmDialog';
```

А файл на диске называется **`ConfirmDialogs.jsx`** — с буквой `s` на конце (внутри, кстати, компонент объявлен правильно — `ConfirmDialog`, в единственном числе; разъехалось именно имя файла). Webpack/CRA ищет `./components/ConfirmDialog` → `ConfirmDialog.jsx` или `ConfirmDialog.js` — и не находит, потому что файл назван иначе:

```
Module not found: Error: Can't resolve './components/ConfirmDialog' in 'src'
```

**Почему это всплыло именно сейчас (и это та же история, что в первом ревью с папкой `SRC`):** на Windows и macOS файловая система не различает регистр и иногда «прощает» близкие имена, а на Linux — нет, имя должно совпасть символ в символ. Поэтому у вас локально, скорее всего, всё открывалось, а на сборочной машине упало бы сразу.

**Что сделать:** привести к одному имени. Либо переименуйте файл `ConfirmDialogs.jsx` → `ConfirmDialog.jsx`, либо поправьте импорт на `./components/ConfirmDialogs`. Я бы выбрал первое — компонент один, и имя в единственном числе честнее отражает суть. Только помните про регистронезависимую ФС: переименование через git делайте явно (`git mv`), иначе git может не заметить смену имени.

## 🟡 Проверьте: проп для отрисовки кнопок в колонке `Table`

В `App.js` колонка «Действия» описана так:

```javascript
{
  title: 'Действия',
  cell: (row) => ( <Button .../> ),
}
```

Сама идея правильная — рисовать кнопки через колонку, а не подмешивать в данные (ровно то, что советовали в прошлый раз). Но проверьте имя пропа: у `Table` из `@consta/uikit` (у вас v5) функция-отрисовщик ячейки обычно называется **`renderCell`**, а не `cell`. Если проп назван не так, как ждёт Consta, колонка просто отрисуется пустой — кнопок «Редактировать/Удалить» в таблице не будет, и при этом никакой ошибки в консоли не появится.

Я не смог проверить точно (зависимости не установлены в моём окружении), поэтому — запустите и посмотрите глазами: появились ли кнопки в последней колонке. Если нет — переименуйте `cell` → `renderCell` и сверьтесь с сигнатурой в документации вашей версии Consta.

## 🟡 Мелочи

- **`WorkForm.jsx`, строка 38** — валидация номера документа всё ещё через `alert('Номер документа обязателен')`. По остальному проекту вы перешли на `SnackBar` — здесь остался последний `alert`. Логичнее показать ошибку тем же способом, что и везде (или подсветить поле через `status="alert"` у `TextField`), чтобы уведомления были единообразными.
- **`onChange` в `TextField`** — значение может прийти как `null` (когда поле очистили). В `FilterPanel` вы это уже подстраховали (`value || ''`), а в `WorkForm` — нет: `onChange={({ value }) => setFormData({ ...formData, doc_number: value })}` положит `null` в управляемое поле, и React может ругнуться на «controlled → uncontrolled». Мелочь, но лучше тоже привести к `value || ''`.
- **Версии пакетов** — в `package.json` React 19 при `react-scripts@5.0.1` (CRA официально рассчитан на React 18). Обычно заводится, но при `npm install` могут вылезти конфликты peer-зависимостей. Если установка ругается — это объяснимо; имейте в виду на случай, когда проект будут поднимать с нуля.
